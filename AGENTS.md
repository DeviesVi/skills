# Codex Preferences

- For Python work in this repository or these skills, use `uv` for Python installation, virtual environments, dependency resolution, script execution, and package management.
- Do not use `pyenv` or system-installed Python for project workflows unless the user explicitly asks for an exception.
- Prefer commands such as `uv run`, `uv sync`, `uv add`, and `uv lock` over direct `python`, `pip`, or manually managed virtual environments.
