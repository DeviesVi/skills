# Report Templates

Use these formats for substantive stock reports. Their coverage keeps the analysis consistent; a focused follow-up or an explicit request for brevity can use a direct answer with the relevant evidence, dates, and uncertainty.

Rules:
- Use the selected format's order by default. The user's requested format takes precedence. Localize headings to the answer's language.
- Preserve material coverage; combine adjacent sections for a concise note rather than repeating facts. Keep the Full Investment Memo sections for a requested deep dive unless the user specifies another structure.
- Mark material missing evidence as "未验证/暂无可靠数据" or its equivalent in the answer's language and explain how it limits the conclusion. Omit irrelevant metrics or explain why an expected metric is inapplicable; do not fill a report with empty sections.
- Keep facts, estimates, and judgment separated.
- Cite material claims near the evidence and include dates for market data, financial periods, filings, and major news. A separate source list can supplement inline citations.
- Use concise prose under each heading unless the user asks for a full report.

## Quick Stock Note

Use for a broad single-stock request. Combine adjacent sections when this makes the note easier to read. For a one-metric question or an explicit short answer, answer directly instead.

Default coverage, in order:

1. Conclusion
2. Data Freshness
3. Company And Business
4. Key Metrics
5. Recent News That Matters
6. Buffett/Munger/Duan Gates
7. Valuation View With P/E Percentile
8. Main Risks
9. Watch Items
10. Sources

Each topic can be brief. Integrate the philosophy gates into the business, valuation, and risk discussion when a separate block would repeat the same conclusions.

## Full Investment Memo

Use for detailed research:

Required headings:

1. Executive Summary
2. Data Freshness And Source Log
3. Company Overview And Business Model
4. Industry And Competitive Position
5. Financial Analysis
6. Investment Philosophy Gates
7. Valuation
8. Peer Comparison
9. News, Catalysts, And Market Narrative
10. Risks And Red Flags
11. Watch Items
12. Conclusion With Fair Value Range And Margin Of Safety

## News-Aware Value Memo

Use when the user asks for current market news plus value investing view:

Default coverage, in order:

1. Current Snapshot
2. Freshness Check
3. Long-Term Thesis
4. Recent News Table
5. Fundamentals
6. Valuation
7. Risk
8. Decision View

## Valuation-Focused Note

Use when the user mainly asks whether the stock is cheap, expensive, worth buying, or what fair value should be.

Default coverage, in order:

1. Valuation Conclusion
2. Data Freshness
3. Current Market Implied Expectations
4. Normalized Earnings Or Owner Earnings
5. Multiple-Based Valuation And P/E Percentile
6. DCF Or FCF Yield Check
7. Margin Of Safety
8. Sensitivity
9. What Would Change The View
10. Sources

## Risk Review

Use when the user mainly asks about downside, accounting problems, leverage, regulatory exposure, or thesis failure.

Default coverage, in order:

1. Risk Conclusion
2. Data Freshness
3. Permanent Impairment Risks
4. Financial And Accounting Risks
5. Business And Competitive Risks
6. Management, Governance, And Capital Allocation
7. News Or Event Risks
8. Balance Sheet And Liquidity
9. Red Flags To Monitor
10. Sources
